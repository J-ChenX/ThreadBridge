# 图标专项审查 · 0.1.21

## 方向与范围

沿用续桥的灰黑、简洁界面。现代感来自统一的圆角线条、视觉重心与状态层；灵动来自响应操作的轻量动效。范围覆盖主页、侧边栏、对话、过程、菜单、新建选择页、配对页及应用标记。系统扫描器内部控件沿用系统行为。

## 独立验收项

| 审查项 | 处理及证据 |
| --- | --- |
| 视觉语言 | 24 个基础符号加 2 个状态变体，共用 24×24 网格、1.75 描边、圆头和圆角连接；三个更多圆点使用实心几何。设置、扫码也接入 BridgeIcons。 |
| 视觉重心 | 设备屏幕与底座收拢；文件夹标签用曲线衔接；图钉倾斜并校正位置，避免生硬的竖直 T 形。导航、箭头、加号保持居中。 |
| 语义 | 设备/项目使用屏幕/文件夹；返回、展开、发送、回到最新分别使用相应方向；设置为调节滑杆，扫码保留二维码识别框。 |
| 状态 | 收藏、置顶有轮廓与 18% 轻填充两种状态；搜索开启时有圆形选中底色；禁用发送减弱对比度。状态同时保留语义说明。 |
| 灵动 | 图标按钮按下缩至 92%，菜单及操作项缩至 94%；释放恢复。展开箭头连续旋转，所有变化使用 BridgeMotion 时长并遵循系统动画缩放。 |
| 小尺寸 | 从实际 Kotlin 路径导出 14/18/20/24dp 浅深色对照，前三档使用较弱的次级文字色以检查保守对比度；14dp 主要用于置顶/收藏标记，复杂扫码图标实际使用 24dp。 |
| 点击与焦点 | 图标视觉尺寸与 48dp 触控范围分开；无文字按钮提供说明，装饰性图标不重复朗读；键盘焦点有可见轮廓。 |
| 应用标记 | 原应用圆角对话标记与整体语言相符，保留其识别度。 |

## 可复验材料

实现：`android/app/src/main/java/dev/threadbridge/BridgeDesign.kt`。导出工具：`tests/android/render_icon_audit.py`，直接读取 Compose 路径，生成 `artifacts/ui-0.1.19-icon-audit.svg`，可用 SVG 渲染器转为 PNG 查看。

实际 APK 的菜单、长按操作、搜索选中态、选择页、按压与键盘焦点通过专用模拟器检查；动画中间帧、系统禁用动画、大字体、浅深色、手机及平板横竖屏由 `qa_android_polish018.py` 与兼容的 UI16/UI17 脚本复验。模拟器验证不能代表所有真机的帧率和触感。

0.1.19 新增图片缩放的 Minus 和缩略图展开的 Expand，沿用 24 网格、1.75 圆头笔画；共 22 个基础图标与 2 个选中状态。审查图通过 render_icon_audit.py 直接导出当前 Kotlin 路径，查看器关闭、缩放按钮沿用 48dp 触控与轻按压反馈。

0.1.21 增加 Eye/EyeOff 密钥可见性图标，沿用 1.75 圆头描边、24 网格、48dp 按钮及共享按压/交叉淡入时长；提供“显示连接密钥/隐藏连接密钥”语义，系统关闭动画时即时更新。审查工具支持实际 Kotlin 的 cubic curveTo 路径，共导出 26 个符号（24 基础加 2 选中状态）。
