# Android 客户端

## 当前实现

M01 使用 Kotlin、Compose 与 Room，显示用户文字、图片、助手的可见过程说明及最终回复。工具调用、内部推理和文件修改卡片不进入对话。当前应用为 `dev.threadbridge`、0.1.14-test、versionCode 15；debug 包添加 `.debug`。Room schema 为版本 4，版本 1/2/3/4 导出位于 `android/app/schemas/`。

配对支持地址和一次性码、二维码。Android Keystore AES-GCM 保护凭证；系统备份与迁移排除凭证及缓存。正式连接要求 HTTPS；私人 IP HTTP 仅在显式局域网测试时可用。关闭重定向，不向跳转地址转发凭证。

发送前持久保存不可变请求；网络失败显示提交待确认。先查原请求，再按有效期和同一快照重试；unknown 不自动重发。离线可读缓存并编辑草稿。已确认发送通过用户消息显示，不重复放在助手回复后的回执中；未确认/失败保留状态和操作。

## 同步与缓存

前台仅一组同步会话，事件唤醒合并、退避重连和周期补核对。后台关闭连接，恢复前台重新鉴权。正文请求失败不阻断回执查询；命令按单调状态合并。配对、清除、草稿和同步使用代际及串行门，旧会话不能写入新账户缓存。

正文分页使用 `(ordinal,id)`；分段绑定消息版本，最多缓存 128 段。消息缓存最多 5000 条、首段正文预算约 16 MiB；草稿与待确认请求独立保护。历史继续按页加载，不要求一次渲染全部内容。

图片通过已鉴权的消息附件接口读取，内容摘要校验后存入私有缓存（最多 64 MiB），显示缩略图并支持点击预览。配对、清除、对话删除及 collection 重置清理对应图片；不加载任意外部图片 URL。图片正文标记沿用消息字段；3→4 迁移仅增加未读/排序元数据，不增加图片表。

Room 1→2 增加 chunks，2→3 增加主机缓存，3→4 增加消息变化标记及毫秒级活动时间，保留原有对话、草稿、配对和已读记录；旧 Hub 缺少新增字段时按 0 兼容。collection generation 改变时，成功同步后清除旧消息、分段、对话、草稿、待确认记录和游标，保留凭证及新主机列表。长按删除共享同步副本，不删除原 Codex 对话；服务端 tombstone 防止回填。

## 呈现与通知

主页顶部显示“设备列表”，按设备分组，设备名称吸顶，其下 28dp 渐隐遮罩柔化经过的对话条目；正常位置不启用遮罩。对话行最小 44dp、20sp 行高，设备名称加重，数量及展开按钮弱化；空设备可见。设备和对话按最新可见消息的毫秒级活动时间与线程更新时间的较大值排序；每台默认显示最近 5 个对话加所有未读对话，更多通过第二层展开/收起查看。设备及对话蓝点表示本机未读，打开对话或在最新位置看到更新后消失，设备在线状态不再用圆点表示。离线启动也从缓存恢复未读蓝点。已读标记按更新时间、完成回复修订号及持久消息变化标记保存到本机 SharedPreferences；进行中消息即使同一时间戳也触发未读，重复导入与仅名称/在线状态改变不触发；消息变化标记为 0 时沿用旧已读格式，配对/集合重置时清除；首次升级同步的已有对话作为已读基线，避免历史导入让所有设备变成未读。系统浅色/深色统一中性色；用户右侧气泡，助手直接排版。输入栏收起时高度 52dp、左右各留白 32dp、底部留白 32dp；获焦后扩大至至少 100dp、左右留白 12dp、键盘上方留白 12dp，按多行内容继续增高（最多六行）。一个 160ms 过渡统一驱动宽度、高度和底部间距，在测量阶段读取进度；键盘避让由 IME insets 驱动，两者同时开始。键盘动画目标在收起开始时清除焦点，返回、导航或菜单打开时同样折叠，草稿保留。对话正文占用完整视口，延伸至浮动控件下方，状态栏/刘海区域完全遮住正文，其下方开始渐隐；底部渐变持续至屏幕底边，上下遮罩不拦截触摸；顶部左右为圆形按钮，对话标题在菜单中查看。列表首尾留白跟随实际测量的控件高度，适应键盘、草稿和字体缩放。主页下拉同步；对话拉过最新底部边缘同步，拉过最早顶部边缘加载更早消息，本地分页读完后使用电脑历史游标加载。普通阅读滑动不触发边缘操作，拉动达到 96dp 后松开执行，进行中的操作不重复提交。右上角只保留标题和连接状态；设置在主页。回到最新按钮在停止滚动 3 秒后隐藏，重新滚动时显示，点击立即在下一次测量定位最新消息，不等待网络也不执行长距离滚动动画。草稿自动保存和恢复，输入框下方不再显示离线/草稿提示，恢复过程不显示占位文字；本地草稿读取不等待网络同步锁，尚未落库的当前草稿由带会话代次校验的临时缓存恢复，持久写入仍沿用串行同步门。输入框浅色模式统一白色，周围以轻阴影和渐变衔接正文，深色沿用主题颜色。

CommonMark 与 GFM 表格渲染为可选择 Compose 文本；不用 WebView，不执行 HTML/脚本或加载远程图片。链接仅在用户点击后交给系统。

后台通知当前沿用 ntfy，`threadbridge://thread/{id}` 仅导航，再经鉴权加载正文。APK 直接 UnifiedPush/FCM、通知栏回复和远程审批尚未开放。

## 验证

JVM 用例位于 `android/app/src/test/`，覆盖缓存同步门、消息格式、回执、默认连接迁移和呈现策略。`tests/android/` 使用专用模拟器和合成 Hub 验证实际 UI；`scripts/android_preview.py` 提供 loopback 像素预览。`qa_android_ui014.py` 验证主页预览/展开、蓝点及持久化、设备排序与吸顶截图；`qa_android_ui013.py` 验证刷新手势、历史分页、按钮闲置隐藏/即时跳转、离线时输入栏高度不变和白色输入框；`qa_android_ui012.py` 记录上一版的输入框展开/收起、底部间距、多行草稿、IME 收起、菜单/导航、长回复跳转及深浅色/大字体截图。模拟器数据与真实 Hub 隔离。

`testDebugUnitTest`、`lintDebug`、`assembleDebug` 不需要 release 签名。`scripts/build-apk.sh` 验证 release、Lint、签名和 16 KiB 对齐。小米 Android 16、扫码、系统重启、移动网络、锁屏通知、真实键盘和覆盖升级仍需真机验收。
