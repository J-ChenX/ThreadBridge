# Android 客户端

## 当前实现

M01 使用 Kotlin、Compose 与 Room，显示用户文字、图片、助手的可见过程说明及最终回复。工具调用、内部推理和文件修改卡片不进入对话。当前应用为 `dev.threadbridge`、0.1.21-test、versionCode 22；debug 包添加 `.debug`。Room schema 为版本 6，版本 1/2/3/4/5/6 导出位于 `android/app/schemas/`。

配对支持地址和一次性码、二维码。Android Keystore AES-GCM 保护凭证；系统备份与迁移排除凭证及缓存。正式连接要求 HTTPS；私人 IP HTTP 仅在显式局域网测试时可用。关闭重定向，不向跳转地址转发凭证。

发送前持久保存不可变请求；网络失败显示提交待确认。先查原请求，再按有效期和同一快照重试；unknown 不自动重发。离线可读缓存并编辑草稿。已确认发送通过用户消息显示，不重复放在助手回复后的回执中；未确认/失败保留状态和操作。

## 同步与缓存

前台仅一组同步会话，事件唤醒合并、退避重连和周期补核对。后台关闭连接，恢复前台重新鉴权。正文请求失败不阻断回执查询；命令按单调状态合并。配对、清除、草稿和同步使用代际及串行门，旧会话不能写入新账户缓存。

正文分页使用 `(ordinal,id)`；分段绑定消息版本，最多缓存 128 段。消息缓存最多 5000 条、首段正文预算约 16 MiB；草稿与待确认请求独立保护。历史继续按页加载，不要求一次渲染全部内容。

图片通过已鉴权的消息附件接口读取，内容摘要校验后存入私有缓存（最多 64 MiB），显示缩略图并支持点击预览。配对、清除、对话删除及 collection 重置清理对应图片；不加载任意外部图片 URL。图片正文标记沿用消息字段；3→4 迁移仅增加未读/排序元数据，不增加图片表。

Room 5→6 增加项目名称及归属已知状态，保留已有缓存、草稿与待确认请求。Room 4→5 增加设备项目目录表、项目归属、本机空白标记及消息时间戳，旧消息时间从毫秒 ordinal 恢复；保留凭证、草稿、待确认请求和已读标记。Room 1→2 增加 chunks，2→3 增加主机缓存，3→4 增加消息变化标记及毫秒级活动时间，保留原有对话、草稿、配对和已读记录；旧 Hub 缺少新增字段时按 0 兼容。collection generation 改变时，成功同步后清除旧消息、分段、对话、草稿、待确认记录和游标，保留凭证及新主机列表。长按删除共享同步副本，不删除原 Codex 对话；服务端 tombstone 防止回填。

## 本机生命周期与新建

空白对话在 Room 保存所选设备与已知项目；设备项目目录由主机 Codex 登记的项目及根目录提供，即使没有当前同步对话也能选择，不读取旧正文。每设备最多返回 100 个项目且目录 JSON 不超过 128 KiB。其他对应设备默认工作目录。首次发送持久保存不可变创建请求；Hub 通过该设备的已验证 capture bridge 执行创建、queue，并返回原生 ID 映射。手机将草稿、待确认请求及置顶/收藏转移到真实 ID 后导航。创建结果未知时仍查询同一请求，不自动创建第二份。只读、离线或未升级的电脑不具备创建能力，手机保留草稿并显示失败/待确认回执。

前台启动和成功同步时最多每 6 小时检查一次 7 天未活动的本机副本，清理 Room 对话、消息、分段、该对话的已完成请求及对应图片，不调用 Hub 删除。非空草稿（包括排队落库）、未知/待确认请求、正在阅读及置顶/收藏受到保护。过期标记由活动时间及消息修订共同确定；相同版本不会被周期同步回填，有新消息可重新进入。离线同样可清理本机缓存。连续同角色消息共用一个时间标记，单条按设备时区显示 `yyyy-MM-dd HH:mm:ss`，多条显示首末完整时间段，旧 Hub 以 ordinal 毫秒兼容。

## 呈现与通知

主页顶部显示“设备列表”，按设备→项目→对话分组，已确认无项目显示“其他”，缺少元数据显示“项目待同步”，设备与项目可独立折叠。设备与当前项目组成双层吸顶，项目划过设备栏下沿后固定，切换项目/设备时替换；其下 16dp 渐隐遮罩柔化经过的对话条目；正常位置不启用遮罩。对话行最小 48dp、19sp 行高，设备名称加重，数量及展开按钮弱化；空设备可见。设备和对话按最新可见消息的毫秒级活动时间与线程更新时间的较大值排序；每个设备项目默认显示最近 3 个对话与所有未读的并集，项目数量显示预览/总数，点击“展开全部”访问其他已读对话，再点“收起到最近与未读”恢复预览；已读只移出预览，不触发删除；本机空白与置顶对话持续显示。长按菜单提供置顶、收藏、删除，置顶项目排在设备内前面，项目内置顶按活动时间排序。收藏保存在本机并从主页右上菜单打开；配对或 collection 重置清除这些本机标记。主页与侧边栏搜索标题支持顺序片段匹配、英文大小写和空白词间隔；250ms 防抖，在线搜索 Hub 最多 1000 个结果，离线搜索本机保留标题。搜索不受预览筛选约束，可重新打开已经清理的副本，缓存及清理仍受本机策略约束。设备及对话蓝点表示本机未读，打开对话或在最新位置看到更新后消失，设备在线状态不再用圆点表示。离线启动也从缓存恢复未读蓝点。已读标记按更新时间、完成回复修订号及持久消息变化标记保存到本机 SharedPreferences；进行中消息即使同一时间戳也触发未读，重复导入与仅名称/在线状态改变不触发；消息变化标记为 0 时沿用旧已读格式，配对/集合重置时清除；首次升级同步的已有对话作为已读基线，避免历史导入让所有设备变成未读。系统浅色/深色统一中性色；用户右侧气泡，助手直接排版。输入栏收起时高度 52dp、左右各留白 32dp、底部留白 32dp；获焦后扩大至至少 100dp、左右留白 12dp、键盘上方留白 12dp，按多行内容继续增高（最多六行）。一个 160ms 过渡统一驱动宽度、高度和底部间距，在测量阶段读取进度；键盘避让由 IME insets 驱动，两者同时开始。键盘动画目标在收起开始时清除焦点，返回、导航或菜单打开时同样折叠，草稿保留。对话正文占用完整视口，延伸至浮动控件下方，状态栏/刘海区域完全遮住正文，其下方开始渐隐；底部渐变持续至屏幕底边，上下遮罩不拦截触摸；顶部仅保留左侧圆形导航按钮，右上菜单及对话内连接状态入口已移除；侧边栏不再显示“续桥”标头。列表首尾留白跟随实际测量的控件高度，适应键盘、草稿和字体缩放。主页下拉同步；对话拉过最新底部边缘同步，拉过最早顶部边缘加载更早消息，本地分页读完后使用电脑历史游标加载。普通阅读滑动不触发边缘操作，拉动达到 96dp 后松开执行，进行中的操作不重复提交。连接状态和设置仅从主页进入。回到最新按钮在停止滚动 3 秒后隐藏，重新滚动时显示，点击立即在下一次测量定位最新消息，不等待网络也不执行长距离滚动动画。草稿自动保存和恢复，输入框下方不再显示离线/草稿提示，恢复过程不显示占位文字；本地草稿读取不等待网络同步锁，尚未落库的当前草稿由带会话代次校验的临时缓存恢复，持久写入仍沿用串行同步门。输入框浅色模式统一白色，周围以轻阴影和渐变衔接正文，深色沿用主题颜色。

CommonMark 与 GFM 表格渲染为可选择 Compose 文本；不用 WebView，不执行 HTML/脚本或加载远程图片。链接仅在用户点击后交给系统。

后台通知当前沿用 ntfy，`threadbridge://thread/{id}` 仅导航，再经鉴权加载正文。APK 直接 UnifiedPush/FCM、通知栏回复和远程审批尚未开放。

## 验证

JVM 用例位于 `android/app/src/test/`，覆盖缓存同步门、消息格式、回执、默认连接迁移和呈现策略。`tests/android/` 使用专用模拟器和合成 Hub 验证实际 UI；`scripts/android_preview.py` 提供 loopback 像素预览。`qa_android_ui015.py` 验证项目两级折叠、最近 3 个、置顶收藏持久化、标题搜索、本机空白创建、消息时间戳及主页唯一连接入口；`qa_android_ui014.py` 保留旧主页预览/展开、蓝点及持久化、设备排序与吸顶截图；`qa_android_ui013.py` 验证刷新手势、历史分页、按钮闲置隐藏/即时跳转、离线时输入栏高度不变和白色输入框；`qa_android_ui012.py` 记录上一版的输入框展开/收起、底部间距、多行草稿、IME 收起、菜单/导航、长回复跳转及深浅色/大字体截图。模拟器数据与真实 Hub 隔离。

`testDebugUnitTest`、`lintDebug`、`assembleDebug` 不需要 release 签名。`scripts/build-apk.sh` 验证 release、Lint、签名和 16 KiB 对齐。小米 Android 16、扫码、系统重启、移动网络、锁屏通知、真实键盘和覆盖升级仍需真机验收。

### 界面细节与动效

保留白色/深灰底、直接阅读的助手正文与右侧用户气泡。导航和常用动作由 BridgeDesign 的统一圆角线条矢量图标构成（1.75 单位描边），含设置与扫码，主图标 20–24dp，辅助标记 14–18dp；交互区域至少 48dp。列表及选择项使用 16dp 圆角反馈，图标按钮为圆形，过程控制为紧凑胶囊；不使用整行矩形水波纹。置顶图钉采用斜向轮廓，收藏/置顶选中有轻填充变体，搜索启用有选中底色；菜单和操作图标按压缩放 94%。专项验收见 [图标专项审查](../图标专项审查.md)。点击反馈显式绑定统一 indication，避免局部主题覆盖；高亮仅改变绘制层，图标按下略微缩放，不改变布局边界；菜单、项目/设备、选择页沿用同一反馈。宽屏对话与输入区最大阅读宽度 720dp，按实际窗口大小计算正文边距。次级文字浅色为 #686868、深色为 #B5B5B5，保持对比度。

BridgeMotion 区分按下 90ms、释放 140ms、箭头/选择切换 180ms、过程展开 220ms及内容淡入 120ms；遵循系统动画时长缩放。浅灰选中态用同一 RGB 的透明端点过渡，避免透明黑色插值造成中间帧发暗。展开箭头连续旋转，不切换两套字形。过程展开/收起与淡入淡出保持顶部控制位置，在本帧的重新测量中补偿反向列表锚点，取消旧的异步滚动补偿；动画中用户滚动优先，快速反向点击收敛到最新状态。过程内容位于控制下方，使用轻量引导线，最终回复不隐藏。搜索输入、新建选择页、回到最新按钮按操作作短过渡，不使用持续跳动或装饰性循环动画。

`qa_android_polish018.py` 在合成 Hub 和专用模拟器录制展开视频，采样中间帧检查过程控制位置，复验按住状态、快速反转、系统禁用动画、小屏、2倍字体深色、横屏及平板横竖屏，以及输入栏尺寸、发送触控区域、草稿恢复和键盘焦点；不会向真实 Codex 提交消息。该验证不替代真实手机的帧率与触感验收。

0.1.19 图片使用全屏浅/深色查看器，48dp 圆形关闭控件、底部缩放胶囊、双指缩放/拖动、双击放大与复位，缩放范围 1–5 倍，平移按实际适配图片尺寸约束；系统返回关闭并保留对话位置。缩略图在加载前后保留 220×164dp，解码最长边 720，打开预览才按 1600 加载；原始摘要校验/鉴权缓存继续使用。解码 Bitmap 使用 8 MiB LRU，删除/七天清理/重新配对/集合重置时清除对应内存记录。图片样本数、焦点与边界见 JVM 用例；真实双指操作仍需手机验证。

0.1.20 连接状态以已鉴权的 HTTP 同步结果为准；WebSocket 被代理拒绝时改为前台 3 秒轮询，不将可用 HTTP 误报离线。HTTP 404 HTML、无效成功响应、鉴权/网络/TLS 失败提供固定诊断文案，不显示响应正文或任意异常文本。恢复同步时清除失败原因，断线不清除本机对话、草稿或凭证。构建读取本机私有公网迁移配置，旧入口名单精确匹配并验证目标的主机身份后迁移；其他配对不受影响。

0.1.21 设置提供服务器地址、遮蔽的连接密钥与显示/隐藏控件、局域网开关、验证并保存。保存前检查 `/v1/hosts` 鉴权和 collection 身份，先冲刷草稿写入，再通过同步门提交新凭证；验证失败不更改原配置或代际，成功提交后使旧队列失效并重启连接，同库保留 Room、草稿、收藏和待处理发送。新密钥只保存在不可保存的 Compose 状态，已存密钥不回显，空值沿用当前密钥。重新配对独立确认本机数据清除。首次连接页支持配对码和手机访问密钥两种模式。
