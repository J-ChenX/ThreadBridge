# 产品约束

本文件保留已批准的产品与架构选择。实现位置和当前验收限制见 [ARCHITECTURE.md](ARCHITECTURE.md)，配置和运行状态属于具体部署，不随源码发布。

## 已批准的目标与边界

| ID | 约束 |
|---|---|
| R01 | 手机查看用户消息和完整最终回复，按原 thread ID 继续已有对话并保留上下文 |
| R02 | 提供可安装 Android APK，目标真机包含小米 Android 16 |
| R03 | 手机公网接入不要求 VPN；优先已有 cpolar 入口，核验 TLS 终止位置 |
| R04 | 个人单用户、一部主手机、四台执行电脑；常开电脑兼任 Hub |
| R05 | 首期不依赖 Google Play；优先已有 ntfy，后续按实测评估 UnifiedPush/FCM |
| R06 | Rust 核心、Kotlin 原生 Compose/Room；不为统一语言引入 JNI |
| R07 | 聊天显示用户文字与图片、助手可见过程说明（commentary）、已确认最终回复与状态；不同步工具调用、工具输出、内部推理或文件修改卡片 |
| R08 | 离线或忙碌保留草稿，恢复后由用户发送；unknown 不自动重发 |
| R09 | 标题只用于显示，不能用于身份匹配或消息路由 |
| R10 | 手动一致性备份到当前电脑，人工恢复，不承诺正式 RPO/RTO |
| R11 | 低内存优先，同时考虑 CPU、磁盘、耗电与响应；数据增长不能造成无界工作集 |

后续能力包括手机发送附件、运行中追加/打断、手机审批、通知栏回复和多手机。首期不建设任意终端、远程桌面或多租户执行平台。正文超出支持范围时明确报错，不静默截断。

## 当前需求修订

approved，2026-10-03：优先级为完成时自动保存最终正文、Codex 不运行时仍能读取、手机按原 ID 续聊。保持原桌面实时执行器不再是硬要求；受控 resume 必须验证原 ID、上下文、权限和工具兼容性，不能以 fork 或新 thread 替代。

approved，2026-10-04：四机使用独立身份、捕获库和发送账本，经已有 Tailscale/SSH 信任接入 Hub；统一生命周期由 Hub 电脑的 `threadbridge.target` 管理。捕获和队列服务保留各自边界，不复用剪贴板内容协议。

approved，2026-10-04：采集以持久 cutoff、现存 ID 排除集和 collection generation 为界，仅同步清理后新建的 thread。旧 thread 再次聊天也不接入。长按删除只删除共享 Hub/手机副本并阻止重导入，不修改原 Codex 记录。重置保留主机身份、配置和手机配对；手机成功同步新 generation 后清除旧消息、草稿、待确认状态和游标。服务端保留必要去重意图，未知结果不能因重置再次发送。

approved，2026-10-06：主页与侧边栏采用设备→项目→对话两级折叠，无项目归入“其他”。每设备项目默认显示最近 3 个与全部未读的并集，并提供“展开全部”访问其他已读对话；读完退出预览不会删除本机记录；置顶项及未发送的本机空白对话持续可见，置顶项目在设备内排前，项目内置顶对话按最后活动时间降序。收藏通过主页菜单访问。主页与侧边栏增加标题模糊搜索，在线查找 Hub 副本，离线查找本机缓存，搜索结果不受默认预览数量限制。新建先在手机选择设备与已知项目保存空白对话，首次发送在对应设备创建原生对话。消息显示本机时区的标准时间戳。最后活动满 7 天后清理手机本机副本，检查间隔 6 小时，草稿、未确认发送、正在阅读及置顶/收藏受到保护；不改变 Hub 或 Codex 原始数据。对话页移除右上菜单及连接状态入口，主页保留连接状态；侧边栏去掉“续桥”标头并采用紧凑布局。

界面使用简洁单色样式，空设备仍显示。电脑预览使用实际 APK 和隔离演示数据。

## 资源目标与验收

下列是候选测量目标，不是已达到的成绩或已确认硬指标：Hub 空闲/常用/峰值 RSS 32/64/128 MiB；每个独立 Rust Agent 16/32/64 MiB。合并模式、Python 多机采集、Android、ntfy、TLS 与隧道开销独立计入整体预算。

以一部手机、四主机、四活动任务为基础，测冷启动、历史读取、慢客户端、重连、备份和 24–72 小时持续运行。历史规模取千/万/十万条，正文常用 2–32 KiB，并验证超限拒绝。当前单消息上限 256 KiB；1 MiB/10 MiB 压力输入不构成支持承诺。记录硬件、版本、构建模式、采样方法、内存、CPU、磁盘、耗电和延迟。

超限时先限制缓存、预取与并发，再拒绝新请求；不能降低鉴权、丢弃已确认命令或重发未知命令。架构选择获批不代表实机验收已经通过。

## 项目与消息呈现修订（用户批准 2026-10-06）

项目来源对齐 Codex 已注册项目的名称和根目录，工作目录只有匹配已注册根目录（包括同库工作树）时归属项目；有显式 project_id 时优先使用。未注册目录进入其他，旧索引无项目表时按 cwd 兼容。手机服务升级与项目元数据回填保留原对话、配对和发送账本，不读取正文来猜项目。设备与当前项目组成双层固定栏。过程消息默认收起，可独立向下展开，保持过程栏在屏幕的位置；最终回复直接显示，未知类型不隐藏。连续同角色消息共用时间，单条标准时间戳、多条显示首末时间段。新建选择器使用同主题的分步列表选择，替换浮动下拉。
